# Plugin: Software Engineering Standards (`dev-standards`)

Unified Google Antigravity plugin providing low-overhead always-on guardrails (`rules/AGENTS.md`) paired with progressive-disclosure skills for version control and code documentation:

- **`rules/AGENTS.md`:** Strictly prohibits automatic `git push` execution and mandates invoking `git-commits` and `code-docs` skills when committing or documenting code.
- **`skills/git-commits/SKILL.md`:** Enforces strict commit atomicity and contextualized Conventional Commits in the active project language.
- **`skills/code-docs/SKILL.md`:** Enforces universal code documentation principles and provides on-demand reference guides (`references/*.md`) for Python, Bash/Shell, TypeScript/JavaScript, Rust, Go, C/C++, Java/C#, and SQL.
