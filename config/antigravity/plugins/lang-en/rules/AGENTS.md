# Project Language Policy: English (`lang-en`)

- **Source Code Identifiers:** All code symbols (variables, functions, methods, classes, types, modules, and file names) must be written in **English** unless the existing file already uses another language by project convention.
- **Commits, Code Documentation, and Technical Docs:** All commit messages, inline comments, docstrings, and documentation files must be written in **English**.
- **Writing Style:** Adhere to standard English grammar and spelling. Use concise, direct, professional software engineering terminology in the active voice and imperative mood (e.g., `add`, `fix`, `refactor`, `implement`), avoiding slang, emojis, or verbose filler.
- **Precedence:** Workspace-scoped rules (`.agents/rules/` or project `AGENTS.md`) override this plugin. If `lang-pt` is enabled simultaneously and no workspace rule dictates otherwise, `lang-pt` takes precedence over `lang-en`.
